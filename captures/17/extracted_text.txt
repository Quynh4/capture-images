# SM・GMS店舗向け フィジカルAI事業構想 ー 見る・判断する・動かす ー
AIカメラで売場の「今」を捉え、惣菜（デリカ）を起点に、D-PLANとの連携で店舗業務のループを閉じる

1. **なぜ今か**
コード生成AIにより受託開発の単価・工数は構造的に圧縮される（Gartner：2029年までに60%の組織が小規模開発チームを標準化/情報サービス業倒産は過去10年で最多）。一方、AIの重心は「デジタル」から「物理世界」へ移り、政府はAIロボットで2040年に20兆円市場獲得を掲げる。フィジカルAIの知見を持たない企業は、対応できる市場が縮む。

2. **本質的な目的**
フィジカルAIの知見を社内に積み重ねること。事業単体の初期収益は目的ではなく、実証は「現場でAIを動かす」知見を獲得する手段と位置づける。この知見は、事業の成否とは別に会社に残る。

3. **何をするか**
主要顧客であるSM・GMSの店舗で、AIカメラにより棚残量・売れ行きペース・客数を取得する単サービスから始める。効果が最も大きい惣菜部門を起点に、惣菜の判断エンジン（第一候補：社内のD-PLAN）と連携して、当日の製造量修正・値引き最適化・作業指示で動かす。

4. **なぜ勝てるか**
カメラ・電子棚札・ロボットは他社製の「部品」で構わない。データコムは既存顧客の現場、基幹・POS連携の実装実績、惣菜業務の理解を持ち、D-PLAN開発チームの協力が得られれば「売場の今×時間帯製造計画」という国内に例のない連携になる。部品を売る側ではなく「指示を出す側」に立つ。

5. **ご判断いただきたいこと**
①新事業テーマとしての承認（本質的目的＝知見の蓄積） ②初年度実証予算：人件費を除き1,000万円以内（概算900万円、2026年10月～2027年9月、既存顧客1～2店舗のデリカ部門） ③3～4名の専任・兼務体制と、D-PLAN開発チームとの協議開始（連携オプション収益をD-PLAN事業に計上する方針を含む）

# 事業の構造 情報 → 惣菜 → 単体で成立 → D-PLAN連携で最大化
単体でも成立し知見は積める。連携すれば顧客効果・模倣困難性・D-PLANの収益が同時に伸びる

* **AIカメラで得られる情報**
  棚残量・売れ行きペース・客数・動線・札状態。POSが捉えられない「売場の今」。中でも棚残量と売れ行きペースは、分単位で「今日この後の製造と値引き」を変えられる
* **効果を最大化できるのは惣菜**
  店内製造で「情報→判断→行動」が1店舗で閉じ、粗利率38.5%と全部門最高、廃棄ロスが最大。売場の今を知る価値が最も速く大きく金額に変わる
* **単体事業として成立、ただし弱点も**
  既存顧客の現場・基幹POS連携実績・惣菜業務の理解で差はつくが、単体ではAIカメラベンダーと正面競合し模倣困難性は限定的。効果は「アラートを見て人が動く」範囲
* **判断エンジンはD-PLANが最適**
  時間帯単位の製造計画、計画→発注→作業指示の一気通貫、基幹POS接続を既に持つ強力なプロダクト。連携で「売場の今×製造計画」という国内にない差別化になり、D-PLAN自身の機能・収益も伸びる

| Phase 1 AIカメラ単体 | Phase 2 D-PLAN連携（標準連携） |
| :--- | :--- |
| **提供機能** | 棚残量・売れ行き・客数の可視化、欠品・値引きタイミングのアラートと推奨（人が判断して動く） | 売れ行きに応じた時間帯製造量の動的修正、値引き時刻・幅の算出、電子棚札・作業指示への自動反映 |
| **顧客効果（1店舗・年）/価格** | 約100～150万円（仮定）/初期150万円+月額5万円 | 約200～500万円（実証値参照）/+月額5万円（全機能） |
| **模倣困難性・収益** | 限定的/カメラ月額+初期導入はデータコム | 高い/連携オプション月額はD-PLAN事業に計上。個別連携（顧客基幹等）は基本機能・個別見積 |

D-PLAN開発チームとは本提案の承認後に協議を開始（現時点で合意済みではない）。カメラ側を先に単体で成立させ、D-PLANへは連携APIで情報を渡す形から始め、D-PLAN本体の改修範囲・時期は開発チームのロードマップと負荷を尊重して決める。

出典：効果額は仮定値。連携時はバロー実証（廃棄-13%、売上+2.9%、2026.8）等を参照

# 初年度実証計画・予算・成功基準
既存顧客1～2店舗のデリカ部門で、2026年10月～2027年9月。人件費を除き1,000万円以内

* 1. 2026.10～11 **顧客選定・合意** 既存顧客（D-PLAN導入先を優先）から1～2店舗。基準値を事前合意
* 2. 2026.12～27.2 **設置・データ収集** カメラ4～6台/店とエッジ端末。検知モデル構築
* 3. 2027.2～3 **可視化・アラート** Phase 1 単体サービスの精度と効果を評価
* 4. 2027.3～5 **D-PLAN連携** 連携方式を協議・設計。まず「提案→人が承認」
* 5. 2027.5～7 **実行連携** タブレット作業指示、電子棚札（惣菜限定）へ反映
* 6. 2027.8～9 **評価・判断** 効果確定、商品化と第2ラウンド投資を判断

**成功基準（案）**
対象店舗の惣菜部門で ①廃棄ロス金額 -10%以上 ②欠品（売り切れ時間帯）の減少 ③粗利額の改善 ④見切り・製造計画作業時間の削減。①と③を必達とし、顧客が有償継続を希望することを商品化の条件とする。

**顧客効果と収益の見通し**
1店舗あたり年100～150万円（単体）～200～500万円（連携）の粗利改善余地に対し、顧客負担は年60～120万円で回収1年以内。導入店舗を2→10→30→80→150店と伸ばし、2031年に年間約2.6億円（うちD-PLAN連携オプション0.6億円はD-PLAN事業に計上）。年商・ロス率・削減率は仮定値。

# 中期ロードマップ・主要リスク・ご判断事項
各段階が単体で売れる形にし、次の段階の実績と知見を積み上げる。桁の違う投資は実証結果を見てから

* Phase 1 見る 2026下期～27上期: 惣菜売場のAIカメラで可視化とアラート。単体で成立
* Phase 2 判断する 2027年: 判断エンジンと連携。標準連携=D-PLAN、個別連携=顧客基幹等
* Phase 3 動かす 2028～29年: 作業指示を起点に、AMR・盛付ロボット等を「指示を出す側」として統合
* Phase 4 学ぶ 2029～30年: 多店舗横断の学習、店舗運用プラットフォームとして他業態へ

事業の成否とは別に残るもの：AIカメラの知見は店内動線分析、顧客動作からの棚割分析、従業員配置の最適化、他部門・他業態へ広がる。ロボット統合などの飛躍は構想段階であり、実証結果と技術動向を踏まえて別途判断する。

**主要リスクと対応**
* **技術スタック未確定** ハードは他社製・複数候補。当社は統合・判断層に集中、機器はAPIで差し替え可能に
* **効果が出ない・再現しない** 「提案→人が承認」から始め精度を上げる。成功基準を事前合意し、2027年9月に撤退・継続を判断
* **D-PLAN協力の遅れ・不成立** 単体サービスで事業と知見蓄積を継続。連携収益のD-PLAN計上など協力の利益を明示して協議
* **プライバシー** 映像は店内エッジで処理し外部送信しない。個人を特定しない棚・人数情報のみ保存

**ご判断いただきたいこと**
1. **新事業テーマの承認** 本質的目的を「フィジカルAI知見の蓄積」と位置づける
2. **初年度実証予算の承認** 人件費を除き1,000万円以内（概算900万円）
3. **体制と方針の承認** 3～4名の専任・兼務体制。D-PLAN開発チームとの協議開始（連携オプション収益のD-PLAN計上を含む）
